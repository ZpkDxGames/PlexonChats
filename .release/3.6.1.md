# PlexonChats 3.6.1 — Compact Interactive Chat Event Feedback

PlexonChats 3.6.1 refines the in-game Chat Event presentation introduced in the 3.3–3.6 series without changing event authority, winner selection, rewards, statistics, Discord synchronization, or shared-board Bingo gameplay.

## Chat Event presentation

- Stock event cards no longer repeat `CHAT EVENT`, the event name, `Reward`, and `Time` across multiple lines.
- Active, completed, expired, and cancelled cards use compact state symbols: `✦`, `✔`, `⌛`, and `✕`.
- Reward and timer metadata use `◆` and `⏱` with Adventure hover descriptions.
- The winner line uses `♛` and exposes total/per-type win statistics through hover text instead of dedicated visible lines.
- Successful events show the canonical answer directly in the completion card.
- TYPE, UNSCRAMBLE, MATH, and REVERSE stock prompts were shortened to avoid repeating the event type in the challenge itself.
- Bingo start/draw/invalid-claim feedback was tightened while preserving its existing authoritative shared board and automatic marking model.

## Configuration migration

Configuration schema advances to **v9**. The v8 → v9 migrator updates only exact known stock presentation strings. Administrator-customized Chat Event cards and prompts are left untouched.

Existing v6/v7/v8 migration behavior remains supported, including administrator-owned event collections and the v7 → v8 Discord webhook migration/secret preservation rules. Upgrades create a `config-before-v9-<timestamp>.yml` backup before the migrated file is written.

## Compatibility

- Paper 26.2
- Java 25 / class major 69
- PlexonCore 2.0.4 API target
- Existing DiscordSRV 1.30.5 event transport support remains unchanged
- Minecraft remains authoritative for Chat Event answers, Bingo claims, rewards, statistics, cancellation, and timeout

No Discord participation or gameplay authority is added by this patch.
