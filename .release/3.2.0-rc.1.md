# PlexonChats 3.2.0-rc.1

Phase 2 premium communication release candidate.

- Rollback baseline: `v3.1.1` / `c7191c21654b11ea55c03e5fecae629e20898319`.
- Preserves the mature PlexonChats-owned LOCAL/GLOBAL routing and synchronous cancellable `PlexonChatEvent`.
- Removes the explicit per-player-chat scheduler handoff while retaining main-thread-safe routing.
- Retains component-based MiniMessage trust boundaries.
- Adds cached-only LuckPerms presentation with Vault fallback and no storage loads in the chat path.
- Adds transactional runtime reload rollback, schema v4 validation, richer diagnostics and explicit auto-message test/enable/disable administration.
- Preserves one shared auto-message scheduler and DiscordSRV no-echo ownership.
- Java 25 / Paper 26.2 / PlexonCore 2.0.4.

**Prerelease only. PlexonCraft runtime certification has not been executed; stable promotion is blocked.**
