# PlexonChats 3.2.0

PlexonChats 3.2.0 is the stable repository closure of the accepted 3.2.0 release-candidate and Phase 3 source lineage.

## Stable product boundary

- Preserves PlexonChats as the single authority for LOCAL/GLOBAL chat routing.
- Preserves synchronous cancellable `PlexonChatEvent` and the public `PlexonChatsAPI` contract used by integrations such as PlexonPanel.
- Preserves first-party `/msg` + `/reply` behavior and aliases `/tell`, `/w`, `/r`.
- Keeps `/ignore` deferred because the consolidation audit found no production evidence requiring it.
- Keeps AFK state outside Chats; PlexonUtility remains the owner of AFK behavior.
- Keeps DiscordSRV integration in Chats with GLOBAL-only export and no echo of Discord-origin traffic.

## Reliability and performance retained

- Native Paper chat routing does not allocate a scheduler task for every message.
- Player/provider presentation avoids synchronous LuckPerms storage loads on the chat path.
- Dynamic chat content is inserted as Adventure components rather than reparsed as trusted MiniMessage.
- Configuration is validated transactionally and runtime refresh failure restores the prior known-good snapshot.
- Scheduled messages use one shared coordinator/task with monotonic deadlines and no catch-up bursts.
- Optional integration failures remain isolated from the core Minecraft chat path.

## Stable release hardening

- Promoted Maven/plugin artifact version from `3.2.0-rc.1` to stable `3.2.0`.
- Generalized Build CI around the project version instead of hard-coded RC filenames/metadata.
- Replaced RC-tag publication with one generic exact-`main` stable release workflow.
- Stable publication rebuilds and retests the exact final production source and refuses prerelease versions, non-main release refs, or pre-existing stable tags.
- Release verification requires a non-empty all-green test suite, Java 25/class major 69, Paper 26.2 metadata, required plugin/API/event/diagnostic classes, non-bundling of provided runtime APIs, checksum verification, provenance, and accepted source ancestry.

## Compatibility

- Java 25
- Paper API `26.2.build.121-stable`
- PlexonCore compile boundary `2.0.4`; supported runtime API remains `>=1.0 <3.0`
- Optional DiscordSRV `1.30.5`
- Rollback baseline: `v3.1.1` / `c7191c21654b11ea55c03e5fecae629e20898319`
