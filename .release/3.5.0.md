# PlexonChats 3.5.0 — shared real-life Bingo correction

PlexonChats 3.5.0 replaces the 3.4.0 participant-specific Bingo gameplay with one server-authoritative shared live board while preserving the accepted Chat Events coordinator, reward profiles, persistent statistics and normal chat architecture.

## Bingo

- One shared 6×6 chat display (`# | B | I | N | G | O` plus five playable rows).
- 25 unique traditional 75-ball values: B 1–15, I 16–30, N 31–45, G 46–60, O 61–75.
- No FREE center; the center is a normal randomized N value.
- One shuffled `1..75` draw pool; calls never repeat.
- Matching board cells mark automatically from authoritative draw history and render as bold green bracketed values.
- `/bingo` privately shows the same authoritative live board.
- Victory is claim-based: `/bingo claim` or exact native public-chat `bingo`.
- Horizontal, vertical and diagonal wins are supported; Full House is optional.
- The first valid atomic claim wins; later claims cannot reward or persist again.
- Timeout, cancellation, shutdown and pool exhaustion produce no reward/statistic.

## Administration and Discord

- `/bingo start|stop|status` delegates to the existing Chat Events manager.
- Existing `/chat events` administration remains available.
- Bingo GUI now shows run/draw/pool/ETA/pattern/board/reward state and Start/Stop controls, with no joining/player-card/manual-mark UI.
- Optional Bingo-specific Discord webhook publishes monospaced ANSI boards asynchronously; the webhook URL is never exposed in diagnostics/GUI/player output.

## Migration

- Configuration schema advances from v6 to v7.
- Pre-upgrade backup: `config-before-v7-<timestamp>.yml`.
- Administrator-owned `chat-events.events` is preserved.
- Explicit BINGO definitions keep their IDs/names/weights/cooldowns/reward references/minimum-online values while obsolete join/FREE/player-card/manual-mark mechanics are removed or ignored.
- A non-Bingo event whose ID is `bingo` remains its explicit type.

## Compatibility

- Paper 26.2
- Java 25 / class major 69
- PlexonCore 2.0.4 compile boundary
- Existing LOCAL/GLOBAL routing, PM/reply, mentions, item display, auto-messages, `PlexonChatsAPI`, synchronous cancellable `PlexonChatEvent`, DiscordSRV normal-chat behavior, reward integrations and `chat-events.db` remain preserved.
