# PlexonChats 3.4.0

PlexonChats 3.4.0 turns Chat Events into a persistent, administratively manageable game system while preserving the accepted 3.3.0 chat architecture.

## Enhanced Chat Event presentation

- Event start, winner, timeout and cancellation states now use configurable multi-line Adventure cards.
- `chat-events.presentation.blank-lines-before` and `blank-lines-after` visually separate events from normal chat without altering the normal public-chat route.
- Event type display names and card line lists are configurable.
- Dynamic player/event values are inserted as safe Components and are never reparsed as trusted MiniMessage source.

## Persistent win statistics

- Adds `plugins/PlexonChats/chat-events.db` using bundled SQLite JDBC.
- Persists per-player total wins, per-type wins, per-definition wins and exact winner history.
- `run_id` is unique at the database boundary, preventing a duplicate completion callback from double-counting.
- Database work runs on one dedicated executor; ordinary chat and winner acceptance perform no synchronous SQLite I/O.
- Adds `/chat events stats`, `/chat events stats <player>` and `/chat events leaderboard` plus GUI statistics and database diagnostics.

## Interactive 75-ball Bingo

- Adds a real `BINGO` event engine instead of treating Bingo as a TYPE/word round.
- Players explicitly join a specific run during the join window; players who do nothing are not participants.
- Each participant receives one server-generated 5x5 B/I/N/G/O board with optional FREE center.
- Draws are unique and participant-only. Non-participants do not receive repeated draw or board traffic.
- Drawn cells are clickable; the server validates the current run, participant, board cell and draw history before marking.
- Supports ROW, COLUMN, DIAGONAL, FOUR_CORNERS and FULL_HOUSE patterns.
- The first valid final mark atomically ends the run; reward, statistics and winner publication each remain exact-once.
- Reconnecting participants recover their existing board while the same run remains active.

## Administration GUI

- `/chat events` opens a live Chat Events dashboard for players and remains text-based for console.
- Adds compact pages for dashboard status, paginated event definitions, event details, reward inspection, Bingo and statistics.
- Event browser interactions: left click opens details, right click previews, shift-left manually starts.
- Existing custom InventoryHolder routing is retained and extended with config revision, page context and active-run identity for stale-action protection.

## Configuration and migration

- Configuration schema advances from v5 to **v6**.
- Migration creates `config-before-v6-<timestamp>.yml` before writing a valid upgraded file.
- Existing administrator-owned event IDs and event definitions are preserved. A legacy v5 TYPE event whose ID is `bingo` is never silently reinterpreted as BINGO.
- Fresh installs use `type-rush` for the TYPE example and `bingo-classic` for the real Bingo definition.
- Invalid v6 candidates reject the complete reload and keep the previous live runtime generation.

## Preserved architecture

- Paper 26.2 / Java 25.
- PlexonCore 2.0.4 compile boundary.
- One accepted LOCAL/GLOBAL public-chat route.
- Synchronous cancellable `PlexonChatEvent` and existing `PlexonChatsAPI`.
- One Chat Events coordinator and one globally active event slot.
- Existing exact-once winner/reward semantics.
- Optional Vault, PlexonKeys, PlaceholderAPI and DiscordSRV integrations remain isolated and are not bundled.
