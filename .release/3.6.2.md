# PlexonChats 3.6.2 — Chat Events Recovery and Content Expansion

PlexonChats 3.6.2 fixes the migration regression that could leave upgraded servers with an empty `chat-events.events` collection. On affected installations this caused `/chat events start <id>` and `/bingo start` to return `NOT_FOUND`, while the Bingo status remained `IDLE` with no active board.

## Chat Events recovery

- Configuration schema advances to **v10**.
- If an upgraded configuration reaches v10 with `chat-events.events` missing or completely empty, PlexonChats restores the complete stock event library from the bundled defaults.
- Non-empty administrator-owned event collections remain untouched. Custom IDs, prompts, rewards, weights, cooldowns, and event data are not merged with or replaced by stock definitions.
- This specifically recovers `type-rush`, `unscramble`, `math-normal`, `math-hard`, `trivia`, `reverse`, and `bingo-classic` on servers affected by the historical empty-collection migration behavior.
- Existing migration backups continue to preserve the exact pre-upgrade configuration as `config-before-v10-<timestamp>.yml`.

## Expanded event content

Stock content is expanded only when the existing values exactly match known Plexon defaults:

- Type Rush grows from 4 stock values to 30 Minecraft/Plexon terms.
- Unscramble grows from 5 words to 35 words.
- Reverse grows from 4 values to 25 values.
- Trivia grows from 2 questions to 15 questions with accepted-answer variants.
- Normal Math adds exact-division rounds and expands its operand range to 2–40.
- Hard Math expands to 12–125 for a wider generated challenge pool.

Administrator-customized pools and ranges are preserved exactly.

## Presentation refresh

The stock v9 Chat Event cards are tightened further:

- active cards use a compact `✦ TYPE • HOW TO PLAY ⓘ` header;
- prompt, reward, timer, and first-winner context fit into a clearer compact card;
- winner cards keep hover statistics while reducing repeated prose;
- timeout and cancellation cards become single-purpose status blocks;
- Bingo start, draw, and invalid-claim feedback use the same compact visual language;
- hover information remains Adventure component based.

## Compatibility and verification

- PlexonCore 2.0.4 API target
