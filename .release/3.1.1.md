# PlexonChats 3.1.1

Core lifecycle compatibility patch for the ecosystem certification wave.

- Supports PlexonCore API `>=1.0 <3.0`.
- Fixes the Core 2 path where successful startup registered `STARTING` but local compatibility gating prevented `markReady()`/`markDegraded()` from publishing the final state.
- Uses owner-aware Core 2 state transitions/unregister semantics while retaining Core 1 fallback behavior.
- Pins CI and release verification to PlexonCore 2.0.4 SHA-256 `61d625a717da9f46ee9231e1970d84b4c317ae12cf4090cdf7c9d39b6a1a9baf`.

No chat routing, formatting, PM, GUI, scheduler, DiscordSRV or player-preference behavior is intentionally changed.
