# PlexonChats Commands and Permissions — 4.0.0

## Player chat

| Command | Permission | Purpose |
| --- | --- | --- |
| `/chat gui` | `plexonchats.gui` | Open player chat/preferences GUI. |
| `/chat channel <local|global>` | channel permission | Select outgoing channel. |
| `/g [message]` | `plexonchats.global` | Select/use GLOBAL chat. |
| `/l [message]` | `plexonchats.local` | Select/use LOCAL chat. |
| `/msg <player> <message>` | `plexonchats.tell` | Send private message. |
| `/reply <message>` | `plexonchats.tell` | Reply to last private-message partner. |
| `/chatitem <token>` | `plexonchats.item` | Open a validated item preview token. |

## Chat Events

| Command | Permission | Purpose |
| --- | --- | --- |
| `/chat events` | `plexonchats.events` | Open event dashboard / console status. |
| `/chat events list` | `plexonchats.events` | List configured event definitions/cooldowns. |
| `/chat events stats [player]` | self: `plexonchats.events`; others: `plexonchats.events.stats.others` | View persistent win statistics. |
| `/chat events leaderboard` | `plexonchats.events` | View cached top winners. |
| `/chat events enable|disable|pause|resume` | `plexonchats.events.manage` | Control event scheduling/master state. |
| `/chat events start <id|random>` | `plexonchats.events.manage` | Manually start a definition. BINGO reserves its lobby. |
| `/chat events stop` | `plexonchats.events.manage` | Cancel the current event without reward/stat. |
| `/chat events preview <id>` | `plexonchats.events.manage` | Preview a definition. |
| `/chat events discord status|test` | `plexonchats.admin.events.discord` | Inspect/test safe Discord presentation state. |

## Bingo

| Command | Permission | Purpose |
| --- | --- | --- |
| `/bingo` | `plexonchats.events.bingo.play` | View your current personal Bingo card. |
| `/bingo join` | `plexonchats.events.bingo.play` | Explicitly join the open lobby and receive a stable personal card. |
| `/bingo leave` | `plexonchats.events.bingo.play` | Leave a lobby; during ACTIVE this forfeits the participant. |
| `/bingo claim` | `plexonchats.events.bingo.play` | Ask the server to validate your manually marked cells against enabled patterns. |
| `/bingo start` | `plexonchats.events.manage` | Open an admin Bingo join lobby. |
| `/bingo start now` | `plexonchats.events.manage` | Activate the admin lobby after at least one explicit participant has joined. |
| `/bingo stop` | `plexonchats.events.manage` | Cancel the lobby/run without reward/stat. |
| `/bingo status` | `plexonchats.events.manage` | Inspect phase, run ID/source, participants, calls, patterns, reward and Discord state. |

Bingo card cells internally call `/bingo mark <run-id> <number>`. That route is intentionally generated by server-controlled clickable components. The run UUID prevents stale chat cards from mutating a newer round; it is not intended as a normal typed player command.

## Administration

| Command | Permission | Purpose |
| --- | --- | --- |
| `/chat admin` | `plexonchats.manage` | Open administration GUI. |
| `/chat status` | `plexonchats.manage` | Inspect runtime/integration state. |
| `/chat diagnostics` | `plexonchats.manage` | Inspect diagnostics without leaking secrets. |
| `/chat reload` | `plexonchats.reload` | Transactionally reload `config.yml` and `data.yml`. |
| `/chat automessages ...` | `plexonchats.automessages` | Manage scheduled messages. |
| `/announce <message>` | `plexonchats.announce` | Server-wide announcement. |

`plexonchats.admin` grants the administrative child permissions declared in `plugin.yml`, including Chat Events/Bingo management and Discord event administration.

## Relevant permission nodes

- `plexonchats.use` — base `/chat` access.
- `plexonchats.global`, `plexonchats.local` — public channels.
- `plexonchats.mention` — player mentions.
- `plexonchats.item` — item display/preview.
- `plexonchats.gui` — player GUI.
- `plexonchats.tell` — PM/reply.
- `plexonchats.events` — event viewing/self stats.
- `plexonchats.events.stats.others` — inspect another player's event stats.
- `plexonchats.events.bingo.play` — join/view/mark/claim Bingo.
- `plexonchats.events.manage` — Chat Events and Bingo administration.
- `plexonchats.admin.events.discord` — Discord event synchronization administration.
- `plexonchats.manage` — administration/status GUI.
- `plexonchats.reload` — config/data reload.
- `plexonchats.automessages` — auto-message administration.
- `plexonchats.formatting`, `plexonchats.formatting.advanced` — formatting capability.
- `plexonchats.bypass.cooldown`, `plexonchats.bypass.private` — trusted bypasses.
- `plexonchats.connection.silent` — suppress custom connection messages for the player.
